Phase 3 Recommendation engine & ML pipeline Weeks 9–12

Better ML approach

🧠
Two-stage ranking
Stage 1: candidate recall via KNN. Stage 2: XGBoost re-ranker on rich features.
🏷
Semantic event tagging
Embed event descriptions with sentence-transformers for cold-start matching
📈
Implicit signals
Track dwell time, scroll depth, share — not just clicks

Feature signals used

Past event attendance
Department & year match
Peer similarity (KNN)
Declared interest tags
Time-of-day preference
🔁
Feedback loop
Post-event ratings retrain model weekly via Celery task

Better UI ideas

🗺 Map view for events
Let students see events plotted on a campus map. Filter by walking distance from current location.
📱 "For You" story reel
Vertical swipe format (like Instagram Stories) for AI-recommended events — higher engagement than a list.
👥 "Friends going" badge
Show avatar stack of peers who registered. Social proof is the single strongest driver of student attendance.
⏳ Urgency indicators
"Only 8 spots left" live counter with a subtle progress bar on each event card. Real-time via Socket.IO.
📆 Week at a glance
Horizontal timeline widget on the home screen showing registered + suggested events across the next 7 days.
🎨 Organizer brand kit
Clubs upload a logo + color palette. Event cards auto-inherit club branding — makes feed feel richer, not generic.
