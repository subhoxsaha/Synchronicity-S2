SELF-HOSTED Fully offline capable
Every tool in this stack can run on a single university server. Postgres + Redis + MinIO + Ollama — no data leaves campus. Critical for GDPR and institutional data policies.
MIT / Apache Permissive licenses
All tools use MIT, Apache 2.0, or BSD licenses. AGPL tools (MinIO, PostHog, Grafana) are fine for internal campus use — AGPL only restricts distributing the software itself.
UPGRADE PATH Cloud-ready
MinIO → S3, Ollama → Claude API, self-hosted Postgres → Neon/Supabase, Redis → Upstash. Every component has a managed cloud equivalent if the team outgrows self-hosting.
