# Campus Event Recommendation Engine Design System

## Core Identity
**Platform**: Web/Mobile, Mobile-first for students, Desktop-first for organizers.
**Vibe**: Modern, clean, slightly playful, highly interactive, premium.
**Typography**: Inter (or Outfit) - clean geometric sans-serif for high readability.

## Color Palette
*   **Primary Action**: Deep Indigo `#4F46E5` (Active states, primary buttons, highlights)
*   **Secondary/Success**: Teal `#14B8A6` (Success states, check-ins, secondary visual interest)
*   **Background (Light Mode)**: Clean White `#FFFFFF` and subtle Gray `#F9FAFB`
*   **Background (Dark Mode)**: Deep Gray/Black `#0F172A` with elevated cards at `#1E293B`
*   **Semantic - Error/Urgency**: Coral/Red `#EF4444` (Almost full capacity, warnings)
*   **Semantic - Warning**: Amber `#F59E0B` (Waitlist, moderate capacity)

## UI Elements & Styling
*   **Corner Radius**: Medium to Large (`8px` for inner elements, `12px` for main cards).
*   **Shadows**: Soft, diffused drop shadows for cards to create depth without being harsh.
*   **Micro-interactions**: 
    *   Spring animations for swipeable cards.
    *   Glassmorphism effects for sticky headers and bottom navigation bars.
*   **Layout**: High whitespace, clear visual hierarchy, emphasis on large imagery (event cover photos).

## Component Guidelines
*   **Cards**: Should feel tactile. "Story Reel" items are vertical, tall rectangles. Main feed cards are wide and image-heavy.
*   **Buttons**: Pill-shaped or heavily rounded rectangles with distinct hover/active scaling states.
*   **Social Proof**: Avatar stacks (overlapping circle profile pictures) used frequently to show "Friends Going".
*   **Progress Indicators**: Thin, bright progress bars used on event cards to indicate remaining capacity (urgency).
